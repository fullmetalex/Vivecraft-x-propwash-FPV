Propwash FPV and Vivecraft jars for Minecraft 26.3 go here; the build compiles against every `*.jar` in this
folder. `python3 scripts/fetch-deps.py` fills it (Vivecraft from Modrinth, Propwash FPV from Modrinth or built from
its source at a release tag). You can also drop the jars in by hand, any loader variant.
